# RAG-ассистент с кешированием и логированием

## 📌 Описание проекта

В проекте реализован простой AI-ассистент на основе технологии **RAG (Retrieval-Augmented Generation)**.

Ассистент умеет:

* искать информацию в базе знаний (ChromaDB)
* генерировать ответы с помощью LLM (OpenAI)
* кешировать ответы для ускорения работы
* логировать все запросы и ответы
* собирать базовые метрики использования

Проект демонстрирует базовую архитектуру AI-ассистента с возможностью анализа его работы.

---

## ⚙️ Реализованный функционал

### 1. RAG (поиск + генерация)

* векторное хранилище: ChromaDB
* эмбеддинги: OpenAI (text-embedding-3-small)
* поиск релевантных документов по смыслу

---

### 2. Кеширование ответов

* ответы сохраняются в `cache.json`
* повторные запросы возвращаются мгновенно
* снижает нагрузку на API

---

### 3. Логирование 

Все запросы сохраняются в SQLite базу `logs.db`:

Фиксируется:

* текст запроса
* ответ
* источник запроса (console / demo / command)
* был ли ответ из кеша
* время ответа (мс)

---

### 4. Метрики системы

Команда `stats` показывает:

* общее количество запросов
* количество попаданий в кеш
* среднее время ответа
* количество документов в базе
* количество записей в кеше

---

## 🏗 Архитектура

```
Пользователь
   ↓
Проверка кеша (cache.py)
   ↓ (если нет)
Поиск в ChromaDB (embeddings.py)
   ↓
Формирование контекста
   ↓
Генерация ответа (rag.py)
   ↓
Сохранение в кеш
   ↓
Логирование (db_logger.py)
   ↓
Ответ пользователю
```

## 🚀 Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/finnik82-75/per07-rag-logging.git
cd per07-rag-logging
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация:

Windows:

```bash
venv\Scripts\Activate.ps1
```

Linux/Mac:

```bash
source venv/bin/activate
```

---

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

### 4. Настройка API ключа

Создать файл `.env`:

```
OPENAI_API_KEY=your_api_key
```

---

### 5. Запуск

```bash
python main.py
```
