# AI-ассистент с RAG, кешированием и логированием запросов

## 📌 Что это даёт

Система отвечает на вопросы по базе знаний и оптимизирует работу AI-ассистента за счёт:

- кеширования (ускорение повторных ответов)
- RAG (повышение релевантности ответов)
- логирования (контроль и аналитика)

👉 Результат:
- снижение нагрузки на API  
- ускорение повторных ответов  
- прозрачность работы ассистента  

Это особенно критично при высокой нагрузке или большом количестве повторяющихся запросов.

---

## 🧠 Где применяется

Подходит для:

- внутренних ассистентов (инструкции, регламенты, базы знаний)  
- поддержки (ответы на типовые вопросы)  
- продаж (работа с продуктовой информацией)  

---

## ⚙️ Как работает система

1. Пользователь задаёт вопрос  
2. Проверяется кеш  
3. Если ответа нет — выполняется поиск в базе (ChromaDB)  
4. Формируется контекст  
5. Генерируется ответ через LLM (OpenAI)  
6. Ответ сохраняется в кеш  
7. Запрос логируется  

Такая схема позволяет:
- избегать лишних обращений к LLM  
- снижать стоимость работы системы  

---

## 🚀 Ключевые компоненты

### RAG (Retrieval-Augmented Generation)

- ChromaDB — векторное хранилище  
- OpenAI embeddings (text-embedding-3-small)  
- семантический поиск  

👉 повышает релевантность ответов за счёт поиска по базе знаний  

---

### Кеширование

- хранение ответов в `cache.json`  
- ключ — хеш запроса  

👉 эффект:
- мгновенные ответы при повторных запросах  
- снижение затрат на API  

---

### Логирование

Все запросы сохраняются в SQLite (`logs.db`)

Фиксируются:

- запрос пользователя  
- ответ системы  
- источник (RAG / cache / команда)  
- время ответа  
- использование кеша  

👉 даёт:
- контроль работы ассистента  
- возможность анализа  
- основу для масштабирования  

---

### Метрики

Команда `stats` показывает:

- количество запросов  
- попадания в кеш  
- среднее время ответа  
- объём базы  

👉 позволяет видеть реальную нагрузку и эффективность системы  

---

## 🧠 Пример работы

Запрос:
Что такое Python?


Первый ответ:
- поиск через RAG  
- время ответа ~3–4 сек  

Повторный запрос:
- ответ из кеша  
- время ответа ~0 сек  

👉 ускорение в 10–50 раз  

👉 система “обучается” на повторных запросах и становится быстрее  

---

## 💡 Команды

- `cache` — показать кеш  
- `clear_cache` — очистить кеш  
- `stats` — статистика  
- `exit` — выход
