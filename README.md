# AI RAG Assistant с кешированием и логированием

## 📌 Описание

AI-ассистент, который отвечает на вопросы по базе знаний с использованием RAG.
Для поиска релевантного контекста применяется ChromaDB, для ускорения повторных ответов — кеширование.
Все запросы и ответы фиксируются в логе, а базовые метрики позволяют оценивать эффективность работы.

---

## 🚀 Бизнес-ценность

- ускорение ответов за счет кеширования
- снижение нагрузки на LLM (экономия денег)
- контроль запросов через логирование
- аналитика использования
- возможность масштабирования

---

## ⚙️ Основная логика работы

1. Пользователь задаёт вопрос
2. Проверяется кеш
3. При отсутствии — выполняется поиск (RAG / ChromaDB)
4. Формируется контекст
5. Генерируется ответ через LLM
6. Ответ сохраняется в кеш
7. Запрос логируется

---

## 🧠 Архитектура

- main.py — управление приложением
- rag.py — логика RAG
- embeddings.py — работа с ChromaDB
- cache.py — кеширование
- db_logger.py — логирование

---

## 📊 Метрики и логирование

- количество запросов
- cache hit
- время ответа
- история запросов

```text
Документов: 9
Запросов: 4
Попаданий в кеш: 1
Среднее время: 3560 ms
```
