# AI-ассистент с RAG, кешированием и логированием запросов

## 📌 Описание проекта

В рамках задания реализован AI-ассистент на базе технологии RAG (Retrieval-Augmented Generation), который:

— ищет ответы в базе знаний  
— кеширует ответы для ускорения повторных запросов  
— логирует все действия пользователя  
— собирает базовые метрики использования  

Проект демонстрирует не только работу RAG, но и добавляет уровень контроля и аналитики.

---

## ⚙️ Основная логика работы

1. Пользователь задаёт вопрос  
2. Проверяется кеш  
3. Если ответа нет — выполняется поиск в базе (ChromaDB)  
4. Формируется контекст  
5. Генерируется ответ через LLM (OpenAI)  
6. Ответ сохраняется в кеш  
7. Данные запроса записываются в лог  

---

## 🚀 Реализованные компоненты

### 1. RAG (Retrieval-Augmented Generation)
— Векторное хранилище: ChromaDB  
— Эмбеддинги: OpenAI (text-embedding-3-small)  
— Семантический поиск по документам  

---

### 2. Кеширование

— Хранение ответов в `cache.json`  
— Ключ — хеш запроса  
— Позволяет:
  - ускорять повторные ответы
  - снижать количество API-запросов  

---

### 3. Логирование (ключевое улучшение)

Все запросы сохраняются в SQLite (`logs.db`)

Фиксируются:

- текст запроса  
- ответ системы  
- источник (RAG / cache / команда)  
- время ответа  
- факт использования кеша  

---

### 4. Метрики системы

Реализована команда `stats`, которая показывает:

- общее количество запросов  
- количество попаданий в кеш  
- среднее время ответа  
- количество документов в базе  

---

## 🧠 Пример работы

Запрос:

Что такое Python?


Первый ответ:
→ поиск через RAG  
→ время ответа ~3–4 секунды  

Повторный запрос:
→ ответ из кеша  
→ мгновенный ответ  

---

## 💡 Доступные команды

В интерактивном режиме:

- `cache` — показать содержимое кеша  
- `clear_cache` — очистить кеш  
- `stats` — статистика системы  
- `exit` — выход  

---

## 📁 Структура проекта


main.py — точка входа
rag.py — логика RAG
embeddings.py — работа с ChromaDB
cache.py — кеширование
db_logger.py — логирование запросов
requirements.txt — зависимости
.env — API ключ (не в репозитории)

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

Запуск:


python main.py
